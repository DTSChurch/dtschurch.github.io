Installing Overflow Gateway

The plugin ships as a single package that mirrors the RockWeb folder structure, so installing is essentially a file copy plus a restart. Rock runs the plugin’s migrations automatically on the next startup — they create the Overflow Financial Gateway, the Overflow admin pages, and the Overflow Sync Job for you. No SQL scripts or Rock Shop account are needed.

Manual install Rock RMS 16.13+

Download the plugin package (v1.0.4)

Heads up — this restarts Rock. Installing or updating the plugin drops a new DLL into Bin, which recycles the application pool and restarts Rock. Active users are briefly logged out and in-progress requests are interrupted, so install during a low-traffic window.

Before You Start

  • Back up the Rock database and the RockWeb folder.
  • Confirm you’re on Rock 16.13 or later.
  • Download the install package (button above): com.overflow.Gateway-1.0.4.zip.

What’s in the Package

The zip mirrors the RockWeb layout, so each item drops into the matching folder:

Package itemCopies to
Bin\com.overflow.Gateway.dllRockWeb\Bin\
Plugins\com_overflow\Gateway\*.obs.js (+ .map)RockWeb\Plugins\com_overflow\Gateway\

Install Steps

  1. Back up the Rock database and the RockWeb folder.
  2. Unzip com.overflow.Gateway-1.0.4.zip.
  3. Copy the Bin and Plugins folders into your site’s RockWeb folder, merging when prompted: 
    …\RockWeb\Bin\com.overflow.Gateway.dll
…\RockWeb\Plugins\com_overflow\Gateway\*.obs.js
  4. Restart Rock — recycle the application pool, or use Admin Tools → Power Tools → Restart Rock. Dropping a new DLL into Bin usually recycles the app automatically.
  5. On startup, the plugin migrations run automatically and create the gateway, admin pages, and job.

Verify the Install

Three quick checks confirm everything was created:

CheckWhere
The Overflow admin page loads with Campaign Maps and Person Maps tabs Browse to /overflow
Overflow Financial Gateway exists Admin Tools → System Settings → Financial Gateways
Overflow Sync Job exists Admin Tools → System Settings → Jobs Administration

Once these are present, continue to the Setup Guide to connect and configure the plugin.

Upgrading an Existing Install

Same process — replace the DLL and the .obs.js files, then restart. Migrations are idempotent: only new ones run, and your settings, campaign maps, person links, and synced data are preserved.

Uninstall / Rollback

To remove the plugin code:

  1. Delete RockWeb\Bin\com.overflow.Gateway.dll.
  2. Delete the RockWeb\Plugins\com_overflow\Gateway\ folder.
  3. Restart Rock.

The database objects — the mapping tables (_com_dtschurch_OverflowPersonMap, _com_dtschurch_OverflowCampaignMap), the gateway, the admin pages, and the job — remain in the database unless you remove them manually. This is intentional so your synced financial history isn’t lost.
