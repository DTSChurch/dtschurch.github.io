Automation & Integrations

Rock Records includes three workflow actions, four field types, authenticated picker endpoints, and generic associations for connecting records to the rest of Rock.

Workflow Actions

ActionUse It ToImportant Inputs
Create Record Type From Workflow TypeCreate or reuse a record type from a workflow type, copy workflow attributes, and optionally backfill workflows as records.Source workflow type, category, optional name/description, copy/include-inactive options, association attribute keys.
Record UpsertCreate or update a record, map workflow values into record attributes, preserve workflow timestamps, and optionally associate an entity.Record reference, name, description, Record Mapping value, entity type and entity reference.
Associate RecordConnect an existing record to a Person, Group, Attribute Matrix, or another Rock entity.Record workflow attribute, entity type, entity reference, optional replace-existing switch and result attribute.

Workflow Migration Pattern

  1. Create a category for the new record types.
  2. Run Create Record Type From Workflow Type with copy disabled to inspect the generated schema first.
  3. Review copied attribute field types, qualifiers, grid flags, and security.
  4. Configure Name, Detail, Header, and Report templates.
  5. If required, rerun with Copy Existing Workflows and decide whether inactive workflows belong in the archive.
  6. Use Record Upsert in the source workflow for future records.

The migration action avoids duplicate record types with the same name and category, and avoids duplicate records when a matching source workflow is already represented.

Authenticated Picker APIs

The Record and Record Type field types call two authenticated POST endpoints. Both return Rock universal tree-picker items and filter selectable types or records through Rock View authorization.

EndpointTree Shape
/api/v2/plugins/org.tpcc/recordtypes/treeCategories as folders, active authorized record types as selectable items.
/api/v2/plugins/org.tpcc/records/treeActive authorized record types as folders, authorized records as selectable items.

These are picker endpoints, not general-purpose CRUD APIs. They require an authenticated Rock request and return only data the current person is authorized to view.

Association Behavior

  • Standard entities are associated by entity type and entity ID.
  • Person references accept Person Alias or Person GUIDs and normalize the association to the Person entity.
  • Attribute Matrix associations can scan matrix items for Person and Group fields and create multiple associations.
  • Associate Record can remove existing associations of the same entity type before adding the new target.

Operational Logging

Version 1.1.3 logs Record List, Record Detail, Associate Record, and Create Record Type From Workflow Type diagnostics through Rock’s logging system. Add the org.tpcc.Records category in Rock Logs at Information or Debug when validating an automation.
