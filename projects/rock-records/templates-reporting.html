Templates & Reporting

Each record type can generate names, replace the standard detail presentation, add a custom header, and produce a PDF with Lava.

Template Roles

TemplateWhen It RunsOutput
Name TemplateAfter a new or updated record is saved without a name.Plain record name.
Detail Header TemplateWhen Record Detail loads an existing record.Rendered HTML above the detail content.
Detail TemplateWhen Record Detail loads and the template is not blank.Rendered HTML replacing the standard view presentation.
Report PDF TemplateWhen a user requests PDF output.Letter-size PDF generated by Rock’s PDF service.

Detail Merge Fields

Detail Header and Detail templates receive these merge fields:

FieldValue
RecordThe current record entity with its loaded attributes.
RecordTypeThe current record type.
CurrentPersonThe person viewing the page.
RecordAttributesA name-sorted list containing each attribute’s Name, Key, formatted Value, and RawValue.
 
<h2>{{ Record.Name }}</h2>
{% for item in RecordAttributes %}
  <dt>{{ item.Name }}</dt>
  <dd>{{ item.Value }}</dd>
{% endfor %}

PDF Merge Fields

The Report PDF template receives Record, RecordType, and the record’s RecordAttributes dictionary. Rock resolves the Lava to HTML and converts that HTML to a Letter-size PDF.

<h1>{{ RecordType.Name }}</h1>
<h2>{{ Record.Name }}</h2>
<p>{{ Record.Description }}</p>
<p>Generated {{ 'Now' | Date:'MMMM d, yyyy' }}</p>
  • The PDF action is available only when the record type has a non-empty report template.
  • Record List can show a PDF download column; Record Detail also exposes a PDF action.
  • Generated file names use the record type name, record name, and a timestamp with special characters removed.

Lava Filters

FilterInputResult
RecordByIdRecord integer IDThe matching Record or null.
RecordsNull or a Rock entity, plus record type IDAll records of that type, or only records associated with the supplied entity.
PeopleWithRecordsRecord type IDPeople associated with at least one record of that type.
 
{% assign record = 42 | RecordById %}
{{ record.Name }}

{% assign notes = Person | Records:3 %}
{% for note in notes %}
  {{ note.Name }}
{% endfor %}

These filters query record data directly. Use them only in Lava surfaces whose page and block security matches the sensitivity of the underlying record type.
